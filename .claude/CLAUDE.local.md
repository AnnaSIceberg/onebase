- List-виджет НЕ поддерживает клик по строке (issue #1617), кнопку обновления (#1618), автообновление (#1619), фильтры (#1620).

### Загрузка справочников
- А_АдресныйКлассификатор: 2.1M записей, FK-ошибки при загрузке. Решено через `ЗагрузитьСправочникМягкий` в `src/загрузкасправочников.proc.os` — FK-ошибки считаются некритичными.

### Нумераторы
- `unique: true` вместе с `period: "year"` требует маску даты — иначе ошибка. Убирать `unique` если не нужна уникальность.

### Формы
- Размещение: `forms/<имя-сущности-в-нижнем-регистре>/объекта.form.yaml` + `.form.os`
- Процессоры: `processors/<Имя>.yaml` + `forms/<имявнижнемрегистре>/объекта.form.*`
- Кнопки и закладки часто уже есть в YAML — перед добавлением новых проверять существующие.
- **hidden_when + form-атрибуты (save:false):** Две ловушки:
  1. При начальном рендере form-атрибутов НЕТ в контексте → `НЕ ПоказатьX` → `НЕ nil` → `true` → элемент не попадает в HTML и не может быть показан позже. **Решение:** инвертировать логику — `hidden_when: "СкрытьX"` (при nil → false → элемент в DOM).
  2. Голое присвоение `ПоказатьX = Истина` пишет в scope интерпретатора, НЕ в obj.Fields. **Решение:** писать через `Объект.СкрытьX = Истина` — это вызывает formObjectThis.Set() → obj.Fields.
  3. Для вызова `ПриОткрытииФормы` при загрузке нужно явное `events: ПриОткрытии: ПриОткрытииФормы` на уровне `form:` в YAML.

### Предопределённые элементы
- Объявляются в YAML через `predefined:` в каталоге. Доступны через `ПредопределённыеЗначения.Справочник.Имя`.
- **БАГ (#1622):** DSL регистронезависимый, имена приходят в lowercase, а SQLite не умеет NOCASE для кириллицы. Обходной путь: имена предопределённых в YAML писать **в нижнем регистре** (`звонокизгосструктур` вместо `ЗвонокИзГосструктур`).
- Миграция НЕ удаляет предопределённые элементы при удалении из YAML. Удалять вручную через Python: `python -c "import sqlite3; conn = sqlite3.connect('...db'); conn.execute(\"DELETE FROM ...\"); conn.commit()"`.
- При смене `_predefined_name` нужно обновить в БД вручную через Python перед миграцией, иначе UNIQUE constraint на `код`.

### DSL
- `Запрос.Выполнить()` возвращает массив, не выборку. Итерация: `Для Каждого Стр Из Результат`.
- `ОтправитьУведомление(ИД, "ui.открытьФорму", Структура)` — открытие формы из кода. Ключ `id` в структуре — **латиницей**, не `ид`!
- Скрыть кнопку «Удалить»: в YAML формы `actions: delete: visible: false`.
- Маска ввода телефона: `input_mask: "(000)000-00-00"`.
- **Открытие обработки из DSL:** `Ссылка = Новый Структура("вид,сущность", "processor", "ИмяОбработки"); ОтправитьУведомление(ИД, "ui.открытьФорму", Ссылка);` — НО параметры передать нельзя (issue #1624).

### Адресный классификатор
- `А_АдресныйКлассификаторИерархия` — иерархический справочник (hierarchical: true): Наименование, ТипНаименования (г, ул, р-н, обл, ...), Родитель.
- `А_АдресныйКлассификатор` — дома: Дом, Корпус, Строение, СсылкаНаМуниципальный → А_АдресныйКлассификаторИерархия.
- Формула ПредставлениеАдреса: `"ТипНаименования Наименование"` для каждого узла (город, улица), `"д Дом корп Корпус стр Строение"` для здания, разделитель `", "`. В 1С — полная иерархия (обход родителей снизу вверх), у нас пока упрощённая (только выбранный город + улица + дом).

### Грабли платформы (найдены 2026-09-28)
- **Bool чекбокс не сохраняется в managed-форме справочника** — ставишь Истина, при открытии снова Ложь (в БД значение корректное, проблема в рендере). Обошли удалением поля.

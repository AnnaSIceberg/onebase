Параметры и команды отчёта занимают несколько широких строк, а Enter в поле может неявно запустить отчёт. Draft добавляет компактный режим всех отчётов и завершение ввода по Enter без запуска. Основной вариант/пресет ждёт явного запуска.

Дата при `ui.short_date_input: true` редактируется по полному шаблону `__.__.____`, дата-время — `__.__.____ __:__:__`. Пользователь вводит цифры; разделители остаются на месте, курсор переходит через них. Backspace/Delete и замена выделенного диапазона сохраняют позиции. Вставка `16.11.2026`, `16112026` и ISO поддерживается; неполная/невозможная дата показывает локализованную ошибку. Enter завершает ввод и сохраняет ISO без отправки отчёта/формы, включая формы с `enter_submits_form`. Escape восстанавливает прежнее значение. Нативный календарь доступен кнопкой и Alt+Down, идентичность исходного поля сохраняется. Ответ серверного события управляемой формы обновляет активную маску; активный редактор даты таблицы завершается перед проверкой изменения/валидности.

Область действия даты: формы объектов, параметры отчётов, отборы списков, все роли, включая операторов КЦ. Изменения даты независимы от ролевой настройки плотности отчёта. Дополнительных изменений операторского интерфейса нет. Ключи формата по-прежнему необязательные: `ui.report_density: compact|dense`, `ui.report_roles`, `ui.report_except_roles`, `ui.short_date_input`; старые SDK строго проверяют app.yaml. Документация и английские сообщения обновлены. Первоначальный сокращённый ввод дня/месяца заменён полным шаблоном по уточнённому заказу 16.11.

Командный интерфейс с тремя папками до команды и чередованием папок/отчётов нельзя выразить нынешними раздельными `items` / `groups`. Нужны рекурсивные упорядоченные узлы, стабильные ID, независимое свёртывание, фильтрация состава/ACL/ролей и сохранение общих/персональных слоёв на любой глубине.

Ранний Draft для самостоятельной разработки. В первом коммите только проект контракта `docs/recursive-command-menu.md`; реализация и SDK ещё в работе. Старые меню, включая меню операторов, должны сохранить прежнее поведение. Прикладные деревья и сопоставление команд переносит владелец конфигурации после готовности движка.

План проверки: публичная загрузка YAML/check, HTTP с ролями и ACL, браузерное дерево из трёх папок со смешанным порядком, клавиатура/aria-expanded/сохранение свёртывания, слои и round-trip, старые flat/section-group меню. В upstream не включаются прикладная конфигурация, исходники внешних систем или данные пользователей.
